# מרכז חומרי הלמידה

מערכת סטטית ליצירת חומרי לימוד תיאורטיים בעברית, המיועדת לפרסום באמצעות GitHub Pages ולהטמעה ב־Notion.

> נקודת הכניסה המחייבת לכל סוכן היא `AGENTS.md`. היררכיית מקורות האמת נמצאת ב־`docs/00-SSOT.md`.

## מקור האמת

- Notion מגדיר את חוזה התוכן, סדר ההסבר, כללי העיצוב ובדיקות האיכות.
- המאגר הזה מגדיר את מימוש ה־HTML, העיצוב והרכיבים החוזרים.
- תוכן תיאורטי נשאר נפרד מתכנון שיעור, הוראות למורה, תרגול והערכה.

## מבנה המערכת

- `index.html` — פיילוט פונקציית `SUM` ב־Excel.
- `gmail.html` — פיילוט כתיבת אימייל חדש ב־Gmail.
- `windows.html` — פיילוט שורת המשימות ב־Windows 11.
- `assets/styles.css` — משתני העיצוב וכל הרכיבים החזותיים במקום אחד.
- `assets/main.js` — התנהגות משותפת: תפריט, העתקה ומעקב גלילה.
- `BLOCKS.md` — חוזה ספריית הבלוקים והשימוש בכל רכיב.
- `docs/` — חוזי התוכן, העיצוב, הרכיבים, התמונות, העבודה והבדיקות.
- `schemas/page-manifest.schema.json` — חוזה נתוני הקלט לדף.
- `content/page-manifest.json` — תבנית הקלט ליצירת דף חדש.

כל רכיב בדף מסומן באמצעות `data-block`. שינוי עיצוב מתבצע במחלקה המשותפת בקובץ העיצוב ולא בתוך הדף.

שלושת הפיילוטים נועדו לבדוק שלושה דפוסי תוכן: הסבר טכני ותחביר, תהליך צעד־אחר־צעד והכרת ממשק. הם אינם CMS ואינם מחולל דפים.

## יצירת דף חדש

1. קראו `AGENTS.md`.
2. העתיקו ומלאו את `content/page-manifest.json`.
3. השתמשו בבלוקים המוגדרים ב־`docs/03-COMPONENT-CONTRACT.md`.
4. בצעו את הבדיקות שב־`docs/06-QA-CONTRACT.md`.

## סדר תוכן מחייב

בסיס → הבנה → התנהגות → יישום. בכל דף נבחרים רק הבלוקים הרלוונטיים לנושא.

## פרסום

בהגדרות המאגר: `Pages` → פרסום מהענף `main` ומתיקיית השורש.
