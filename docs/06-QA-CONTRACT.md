# חוזה QA

## מצבים

`draft` עבודה חלקית; `review` המבנה הושלם והחסרים ידועים; `verified` תוכן, מקורות ונכסים נבדקו; `approved` עבר הכול ואושר; `blocked` חסר מידע או נכס.

## בדיקות וראיות

| תחום | בדיקה | ראיה |
|---|---|---|
| תוכן | נושא אחד וללא תכנון שיעור | סקירת מבנה |
| מקור | כל טענה תלוית־גרסה נתמכת | רשימת מקורות ב־manifest |
| שפה | עברית טבעית ואנגלית רק כשנדרשת | סקירת טקסט |
| RTL | סדר, יישור, טבלאות וניווט | צילום רחב וצר |
| רכיבים | מזהים קיימים וללא CSS כפול | בדיקת קוד |
| תמונות | אמיתיות, מדויקות, קריאות ונגישות | רשומת נכס וצילום דף |
| אייקונים | מקור, גודל ונגישות תקינים | בדיקת DOM וחזות |
| התנהגות | ניווט, קיפול, העתקה וקישורים | בדיקת דפדפן |
| רגרסיה | דפים קיימים לא נשברו | השוואת מסכים |

PASS דורש שכל בדיקות החובה עברו ואין חסימה. בדיקה שלא בוצעה היא `not-run`, לא PASS. דיווח כולל: מה נבדק, תוצאה, ראיה, הערה והצעד הבא היחיד.
