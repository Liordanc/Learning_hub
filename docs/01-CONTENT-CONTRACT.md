# חוזה תוכן

דף לומד הוא חומר תיאורטי עצמאי המלמד נושא, פעולה, מושג או ממשק; הוא אינו מערך שיעור.

## מבנה ברירת מחדל

כותרת → פתיח קצר → מושגים או רכיבי ממשק → הסבר מדורג → דוגמה או צילום → הבחנות ושיטות עבודה → טעויות נפוצות → שאלות נפוצות. מוסיפים רק חלקים בעלי צורך לימודי.

## כללים

- הכותרת הראשית מציינת את הנושא בלבד. אין לחזור בה על שם המוצר או המדור שכבר מוצגים בכותרת האתר ובפירורי הלחם.
- עברית טבעית, משפטים קצרים ופעולה ברורה.
- קודם המונח העברי; השם הרשמי באנגלית נוסף רק לזיהוי.
- פעולה אחת בכל צעד ותוצאה נצפית בסופו.
- אין מידע ניהולי, זמני שיעור, תסריט מורה או הסבר על מבנה הדף.
- נוסחאות, כתובות, קיצורים ושמות ממשק נשמרים בדיוק.

## מקורות

- Google ו־Gmail: מרכז העזרה הרשמי של Google.
- Windows ו־Microsoft 365: Microsoft Support או Microsoft Learn.
- Android ומכשירים: תיעוד Android ותיעוד היצרן לדגם ולגרסה.
- כל מקור נרשם ב־manifest עם יצרן, כותרת, כתובת ותאריך בדיקה.
- תוכן שלא אומת נשאר `draft` ואינו מוצג כעובדה מוגמרת.
