# מקור האמת

## מטרה

יצירת חומרי למידה עקביים בעברית, בלי להמציא מחדש מבנה, עיצוב או כללי בדיקה בכל דף.

## היררכיית סמכות

1. `AGENTS.md` — הפעלה, איסורים וחסימות.
2. החוזה הייעודי בתחום השינוי.
3. `content/page-manifest.json` — נתוני הדף, אם אינם סותרים חוזה.
4. הקוד המשותף ב־`assets/`.
5. דפי דוגמה. דוגמה לעולם אינה גוברת על חוזה.

## מפת החוזים

| מסמך | סמכות יחידה |
|---|---|
| `01-CONTENT-CONTRACT.md` | תוכן, מקורות ושפה |
| `02-DESIGN-CONTRACT.md` | עיצוב, RTL, צבעים ומרווחים |
| `03-COMPONENT-CONTRACT.md` | שמות הבלוקים ותפקידיהם |
| `04-IMAGE-ICON-CONTRACT.md` | תמונות, צילומי ממשק ואייקונים |
| `05-WORKFLOW.md` | סדר הייצור והאוטומציה המותרת |
| `06-QA-CONTRACT.md` | בדיקות, ראיות וסטטוסים |
| `07-DECISIONS.md` | החלטות נעולות |

המערכת היא ספריית מסמכים ורכיבים, לא CMS. בניית ממשק ניהול או מנוע פרסום דורשת החלטה נפרדת.
