# תהליך ייצור

1. הגדרה: נושא אחד, קהל, מוצר, גרסה ויעד למידה.
2. מקורות: מקור רשמי לכל פעולה או טענה תלוית־ממשק.
3. מפת תוכן: בחירת הבלוקים הנחוצים וסידורם לפי מהלך ההבנה.
4. כתיבה: עברית בהירה לפי חוזה התוכן.
5. הרכבה: רכיבים וסגנונות משותפים בלבד.
6. נכסים: תמונות ואייקונים מאומתים או חסימה מפורשת.
7. QA: ביצוע כל הבדיקות ושמירת הראיות.
8. סטטוס: קידום רק כאשר תנאי המצב מתקיימים.

## אוטומציה מותרת

יצירת שלד HTML מתוך manifest, הזרקת תוכן לבלוקים קיימים, יצירת ניווט ובדיקות סטטיות. אסור לאוטומציה להמציא תוכן, מקור, צילום, אייקון או החלטת עיצוב. תוצר אוטומטי מתחיל ב־`draft`. אין לבנות CMS בשלב זה.
