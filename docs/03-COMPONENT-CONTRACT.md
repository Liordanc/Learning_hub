# חוזה רכיבים

בלוק מוגדר לפי תפקיד לימודי. מוצר וצבע הם וריאנט, לא בלוק חדש. כל בלוק מסומן `data-block`.

| מזהה | תפקיד |
|---|---|
| `lead` | פתיח: הגדרה ותועלת |
| `concept` | מושג והסבר |
| `formula-example` | נוסחה, ביטוי או קיצור עם פירוש |
| `syntax` | תבנית תחביר ופירוק רכיבים |
| `information-table` | מידע או השוואה שאינם מתחזים לתוכנה |
| `software-example` | דוגמת תוכנה עם וריאנט מוצר מאומת |
| `interface-map` | צילום אמיתי, סימונים וכיתוב |
| `step-by-step` | פעולה אחת ותוצאה בכל צעד |
| `action-with-icon` | שם פעולה רשמי ואייקון מתאים |
| `distinction` | הבחנה מעשית בין מצבים |
| `example` | קלט, פעולה ותוצאה |
| `best-practices` | שיטות עבודה מומלצות לדיוק או לתחזוקה |
| `note` / `important` / `tip` | מידע משלים / מניעת טעות / ייעול |
| `troubleshooting` | סימפטום, סיבה ופתרון |
| `faq` | שאלה אמיתית ותשובה ישירה |

אין ליצור בלוק ללא צורך, אין לעצב טבלת מידע כממשק תוכנה, ורכיב חוזר מעוצב רק בקובץ המשותף. `components.html` הוא קטלוג חזותי ולא מקור סמכות.
